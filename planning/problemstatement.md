🧩 PROBLEM STATEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Build a single conversational AI assistant that gives every employee instant access to HR, Admin, IT, and Org-level information — eliminating wait times, reducing friction, and freeing teams to focus on what truly matters.
 
Domains to cover:
👤 HR — Leaves · Payroll · Policies · Benefits · Onboarding
🏢 Admin — Policies · Document Requests · Forms
💻 IT — Tool Access · Escalations · Knowledge Base
🌐 Org. Level — Org. Info · Policies · Announcements
 
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ KEY FEATURES TO IMPLEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FAQ Engine — Instant answers on leave, payroll, policies & benefits
Onboarding Guidance — Videos, decks & Nexus links for new joiners
Calendar & Attendance — Holiday schedule & self-attendance info
Smart Escalation — Auto-route unresolved queries to HR / Admin / IT with real-time alerts
Document Generation — Automated NOC letters & employment verification
Form Submissions — Request handling for HR, Admin & IT services
User Feedback Loop — Thumbs up/down + comments on every AI response
Prompt-Level Training — New capabilities via config, zero code changes
